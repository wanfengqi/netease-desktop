## S7 本地音乐扫描

### 元数据解析：已有现成方案
- `music-metadata` **已在 node_modules 中**（NeteaseCloudMusicApi 的传递依赖），版本 **7.14.0**
- **CJS 与 ESM 双可用**：
  - `require('music-metadata')` → `parseFile, parseBuffer, parseStream, selectCover, orderTags`
  - `import('music-metadata')` → 同样可用
- 主进程可直接用，**不需要新装依赖**
- 若要独立版本，registry 上最新为 `12.3.2`（但 7.14.0 已够用，不必升）

### ffmpeg 不在 PATH
- `C:/Program Files/ffmpeg/bin/` 不存在
- **结论**：不要依赖 ffmpeg。时长/比特率等信息全部走 `music-metadata`，它原生读容器头

### 扫描策略（建议）
- 只扫常见扩展名：`.mp3 .flac .m4a .aac .ogg .wav .wma .ape`
- 深度限制（默认 ≤6 层），跳过 `node_modules`、`.git`、系统目录
- 增量扫描：按「路径 + mtime + size」比对，未变的不重解析
- 大批量要进度反馈（流式发 IPC 事件，不要一次 await 全部）
- 元数据缺失时用文件名兜底（如 `歌手 - 歌名.mp3` 的解析规则）

## S7 离线下载

### 约束（已由用户明确选择 D3）
- 用户选择「做完整离线下载：选目录、批量下载、离线播放」
- **边界**：仅本地落盘 + 本应用内离线播放，**不提供任何导出/分享/分发路径**

### 技术要点
- 音频 URL 有时效 → 下载要**边下边校验**，失败可重试
- 下载记录存 `source:id` + 本地路径 + 文件大小 + 校验值
- 离线播放：优先查本地文件，命中则用 `file://` 或自定义协议加载
- **Electron 注意**：`file://` 在渲染进程受 CSP 与安全策略限制，可能需要注册自定义协议
  （如 `app://local/`）或走 `webSecurity` 配置——**S7 执行者必须实测哪种可行并说明**
- 需要新 IPC：`download:start / download:cancel / download:list / download:remove / dialog:chooseDir`

## S8 设置中心

### 音质等级
- **网易云**：`/song/url/v1` 的 `level` 参数，旧版硬编码为 `'exhigh'`
  - 可选值（NeteaseCloudMusicApi 支持）：`standard / higher / exhigh / lossless / hires`（另 `sky` 有特殊处理）
  - **实测注意**：源码里 `if (data.level == 'sky')` 有特殊分支，需避开或单独处理
- **咪咕**：`getUrlH5V24` 的 `toneFlag` 参数，当前默认 `'PQ'`
  - 常见值：`PQ`（普通）/ `HQ`（高清）/ `SQ`（无损）
  - 响应里 `data.audioFormatType` 会回显实际音质
- **S8 要求**：音质选择必须**真正传给取址接口**，不是只存个配置值。改完要能实测不同音质返回的 `br`（比特率）不同

### 全局快捷键（参考旧版 `src/main.js:469-478`）
```js
bind('MediaPlayPause', 'toggle');
bind('MediaNextTrack', 'next');
bind('MediaPreviousTrack', 'prev');
bind('CommandOrControl+Alt+L', 'lyric');   // 桌面歌词开关
```
- 旧版用 `globalShortcut.register` + `mainWin.webContents.send('hotkey', action)`
- `app.on('will-quit', () => globalShortcut.unregisterAll())`
- **S8 要求**：快捷键可配置，且要处理「注册失败」（被别的软件占用）时给用户明确提示

### SMTC（系统媒体控制）
- 旧版用 `navigator.mediaSession`（`setActionHandler` + `MediaMetadata` + `setPositionState`）
- **S8 要求**：迁移到新版，且要在 Windows 系统媒体浮层里真的显示封面与标题

### 托盘
- 旧版 `createTray`：图标 + `setToolTip` + `setContextMenu`
- **注意**：旧版有「图标缺失时用 1x1 透明图兜底」的处理，是新版要继承的健壮性做法

### 主题（6 套皮肤）
- 旧版 `src/renderer/themes.js` 229 行，含取色算法
- 现有 `app/src/styles/base.css` 已是 CSS 变量体系，**接主题只需换变量值**
- **S8 要求**：至少迁移旧版的 6 套内置皮肤，且切换即时生效、持久化
