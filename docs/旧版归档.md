# 旧版归档

新版从 S9 起作为唯一产品入口，不再维护新旧同时运行。

- 归档前基线：`d4fffa0`，附注标签 `legacy-v1`。
- 原 `src/` 使用 `git mv` 迁至 `legacy/src-v1/`，保留逐文件历史。
- `legacy-v1:src/` 是迁移前旧版完整源码；`legacy-v1:src/main.js` 为旧主进程。
- `shots/_*.js` 等临时调试脚本不提交、不进入产品包。

仅查看旧版：

```bash
git show legacy-v1:src/main.js
git log --follow -- legacy/src-v1/main.js
```

需要研究或恢复旧版时，建议另建工作树，避免覆盖当前新版：

```bash
git worktree add ../netease-desktop-legacy legacy-v1
```

旧 release 在重新打包前移到项目外备份，实际路径与大小见《最终验收》。
