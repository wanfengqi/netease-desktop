## 一、网易云（NeteaseCloudMusicApi 4.32.0）

模块总数 **377**。本项目当前只用了 13 个 path：

```
/login/status        /login/token/refresh   /login/qr/key
/login/qr/create     /login/qr/check        /cloudsearch
/search              /song/detail           /song/url/v1
/playlist/detail     /lyric                 /artists
/artist/album        /album                 /comment/music
```

### 本期要新增用到的（已确认模块存在）

| 用途 | 模块 | 备注 |
|---|---|---|
| 首页推荐 | `personalized` | 推荐歌单列表 |

## 三、主进程瘦身现状

`slimPayload`（src/main.js:254）只有 **3 个分支**：

```
/playlist/detail   → 裁 playlist 与 tracks
/cloudsearch       → 裁 result.playlists
/comment/music     → 裁评论字段（原始 70-130KB）
```

**问题**：新增任何接口（本期要加 9 个网易云 + 大量咪咕）都要去主进程加 if 分支，主进程会持续膨胀。
**S2 处置**：瘦身下沉到 `app/src/data/repository/`，每个接口一个方法自带 picker；主进程只保留透传 + 一个可选通用裁剪器。

## 四、咪咕特殊约束（旧代码实测得来，必须继承）

1. **取播放地址只有一个稳定接口**：`getUrlH5V24`（旧代码注释原话："getUrlH5V24 是唯一稳定返回 url 的接口"）
2. **服务端标"60s 试听"但实测返回完整音频** —— UI 需如实标注，但不能据此判定不可播
3. **咪咕图片是相对路径**，必须拼 `https://d.musicapp.migu.cn` 前缀
4. **咪咕时长单位是秒**，必须 ×1000 归一成毫秒
5. **咪咕源不能走 Web Audio 均衡器**（crossOrigin 判定），换歌时 `crossOrigin` 必须在 `src` 之前设好
